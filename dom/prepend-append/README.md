## Prepend/append

### About

This is a mini project to experiment with the prepend, append, and remove Javascript DOM methods.

### Versions

Currently, only version 1 is complete. Clicking on the first button adds an item to the top of the list, clicking on the second adds an item to the bottom, while clicking on the third removes the final item. In the future, I hope to manually create the &lt;ol&gt; ordering by having the program keep track of numbers and shift each item's index automatically when a new item is added to or removed from the top.
