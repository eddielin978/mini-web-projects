## Gacha Chest

### About

This is a mini project to experiment with creating a chest that randomly drops a card/item.

### Versions

Currently, only version 1 is complete. Clicking on 'roll once' gives a random Card of a letter from A-E with 20% odds for each.

### Future Version Plans

Version 2: Different odds for different cards + rarity/odds display upon pull

Version 3: Random soul stone amounts in addition to random rarities/odds

Version 4: Better design (nicer bg, physical card, chest disappears when rolling + placeholder card animation + "Ok" button upon roll)

Version 5: Set rarities (A, B, C, D, E = common; F, G, H = rare; I, J, K = epic) + UI that has greyed out colors for cards that haven't been pulled yet + small number next to each card of cumulative soul stones pulled

Version 6: 10x pull
