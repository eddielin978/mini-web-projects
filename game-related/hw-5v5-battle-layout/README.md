## 5v5 Autobattler Battle Screen Layout

### About

This is a mini project to experiment with creating a battle layout with 5 heroes lined up against each other. There are also cards at the bottom to show character sprites, ranks, and energy.

### Versions

Versions 1 and 2 are complete. Version 1 has the 5v5 formation as well as the player's heroes' cards at the bottom. Version 2 adds energy bars and rank-based borders. Version 3 will have a timer and a pause button that currently won't pause anything. Version 4 will have each hero's energy increase over time and empty if the player clicks on the hero's card when it's full.
