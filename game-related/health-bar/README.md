## Health Bar

### About

This is a mini project to experiment with creating a health bar that scales with a health variable. Health bars are crucial components of many games I plan to create in the future.

### Versions

Currently, only version 1 is complete. Clicking on the health bar container decreases the health variable, down to a minimum of 0. It currently decrements by 5 per click, and the health bar scales accordingly. The plan for version 2 is to have the background color change (with manually set intervals), have a utility decrement function, and have user-select: none on the text. Version 3 will have auto-regen and a nicer bg-color. Version 4 will have the ability to set dmg and also have dmg/heal number displays. Version 5, if I get to that point, will have a div/box with the health bar above it, meaning damage is dealt by clicking the box instead of the health bar. The box will change color when health reaches 0, as well as regen stopping. Version 6 will have multiple objects, each with their own health bar and regen. Version 7 will have some skill buttons (deal dmg to highest health div, AoE heal, etc.).
